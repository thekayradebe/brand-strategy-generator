        05
        
Refine Your Deck


        
Once NotebookLM has generated your deck, you have two options for refining it — depending on whether you have a Canva Pro account.


        


          
          

            

              No Paid Tools Required
              Option A — Refine in NotebookLM
            

            

              
If you don't have Canva Pro, you can make changes without leaving NotebookLM. This approach is more manual but works with any account.


              To edit text or restructure a slide
              
Go back into the NotebookLM chat and ask it to revise specific pages. For example: "Rewrite Page 5 — the content pillar description is too long. Make it shorter and punchier." You can ask it to regenerate individual pages without redoing the whole deck.


              To add images
              
Find the image you want to use — a product photo, a brand asset, a screenshot from the client's website — and upload it into NotebookLM as an additional source. Then prompt NotebookLM: "Using the image I've added, update Page [X] to include this image as the main visual on that slide."

            

          


          
          

            

              Canva Pro Required
              Option B — Refine in Canva with Magic Layers
            

            

              

                Magic Layers is a Canva Pro feature — it is not available on the free plan. As a social media manager, a Canva Pro account is a core professional tool you'll use constantly. If you don't have it yet, this is a good time to get it.
              

              
Magic Layers lets you drop a finished slide image into Canva and automatically separate it into individual editable elements — text, background, shapes, images — so you can edit each one independently. This is the fastest way to customise the NotebookLM deck with real client assets.


              
    
                
  • 
                  1
                  
    Export your slides from NotebookLM. Download or screenshot each slide as a PNG. Save them as slide_01.png through slide_10.png.
    
                
    • 
                
  • 
                  2
                  
    Set up your Canva presentation. Go to canva.com, click Create a design, search for Presentation, and select the 1920 × 1080px widescreen format. Add 10 slides — one for each image.
    
                
    • 
                
  • 
                  3
                  
    Import and separate layers with Magic Layers. For each slide: upload the PNG via Uploads → Upload files. Drag it onto the canvas and fill the frame. Then select the image and click Edit Image → Magic Layers. Canva will separate the image into editable layers — text blocks, shapes, background, photos. Click any text layer to rewrite it. Click any image layer to swap or delete it.
                    
    Magic Layers works best on slides with clearly defined elements. If a slide is very dense, start with the simpler elements first.
    
                  
    
                
    • 
                
  • 
                  4
                  
    Add client product or service images. Go to the client's website and screenshot or save the product image you want. Upload it to Canva via Uploads → Upload files. Click the image and go to Edit Image → Background Remover — Canva will isolate the product. Drag the cleaned image onto the slide and position it to replace the placeholder.
                    
    For better resolution: right-click the image on the client's website and select "Save image as" rather than screenshotting.
    
                  
    
                
    • 
                
  • 
                  5
                  
    Final polish and export. Review all 10 slides for consistency. When you're done, click Share → Download. Choose PDF Print for a high-res single file, or PNG for individual slide images.
